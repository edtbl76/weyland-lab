# Sealed secrets (B69 Wave 2)

Committed `SealedSecret` CRs live here — generated by `scripts/seal-secrets.sh --seal` (one file per secret,
`<ns>__<name>.yaml`). They are **safe for the public repo**: only this cluster's sealed-secrets controller private
key (escrowed off-cluster) can decrypt them. Applied by the `sealed-secrets-manifests` Argo app; each SealedSecret
self-specifies its namespace and the controller reconciles it into the real Secret.

Re-seal a rotated secret: re-run the script (or `kubectl -n <ns> get secret <name> -o yaml | kubeseal --format yaml`)
and overwrite the file. Index of what each secret holds: `docs/runbooks/secrets.md`.
