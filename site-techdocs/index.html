Weyland Docs¶

Weyland is a home AI lab on a Minisforum MS-A2 (Proxmox): local LLM inference, multi-backend RAG, speech-to-text, pipeline orchestration, an eval harness, observability, object storage, and AI agents — all LAN-only. This docs/ tree is the canonical, version-controlled source of truth (and the RAG corpus).

Start here¶

  • arch.md — architecture: topology, components, validated flows, the picture and the why
  • hosts.md — host/container inventory (IPs, access, roles)
  • api.md — live endpoint registry

concepts/ — the why¶

  • llm-inference-cpu-vs-gpu.md — CPU=capacity vs GPU=speed
  • model-serving-hardware.md — MS-A2 sizing, model throughput, context windows
  • agent-platform-design.md — Hermes/OpenClaw lanes, MCP seam, A2A
  • data-schema.md — RAG (4 backends) + eval store schemas, ground-truth-validated

runbooks/ — the how (per service)¶

  • agent-hermes.md — Hermes agent (CT 104) setup, config, gotchas, Kanban (B27)
  • model-gateway.md — LiteLLM hosted-model gateway (Gemini + OpenRouter) + model catalog
  • model-serving-ollama.md — Ollama (CT 102), models, CPU tuning
  • transcription-whisper.md — whisper.cpp STT (CT 103) + OpenAI shim
  • eval-harness.md — LLM eval pipeline, judge panel, leaderboard
  • observability.md — Prometheus + Grafana + Alertmanager
  • service-mesh-istio.md — Istio mesh (B8): install, sidecar injection, mTLS, Kiali/Jaeger, TCP-backend fix
  • storage-minio.md — MinIO object storage
  • aidlc-kb-ingest.md — AIDLC knowledge-base ingest (B37): MinIO source + brand scrub, on-demand Dagster job, Neo4j :Entry graph + GDS, NeoDash viz
  • weyland-idp.md — IDP / Backstage (B3): build-from-git (multi-stage), ConfigMap config, Postgres role, the mesh + guest-auth gotchas

u6–u12 — credential hardening, HF cleanup, Headlamp token, mkcert/CoreDNS/Traefik (U9), SA scoping, SSH identity, health endpoints. (Numbered to backlog units; see aidlc-docs/.)
