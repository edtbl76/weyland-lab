The Realm of Agents

24 small, corpus-backed agents in five groups. Each is a thin composition — a role prompt + a skill family + a slice of the 232-tool MCP surface (via the Bifrost VK) + a brain. A supervisor discovers each via its Agent Card and delegates; leads run their own specialty or delegate to their team.

Brain: every agent currently runs on Claude Haiku (a Realm-wide REALM_MODEL override, resolved through LiteLLM's wl-agentic lane) — fast, reliable, and off the lab's local GPU. The wl-* lanes on each card below are the designed per-agent routing, restored by clearing the override.
