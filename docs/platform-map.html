Weyland · Platform Map · 2026-07

One box. Every tool, and what it's for.

An R&D platform where a governed lakehouse is the substrate and two agent lanes close the loop - Claude Code builds; the operator agent is live, a local-brained (gpt-oss:20b) LangGraph agent on mother. Every technology below runs on a single bare-metal Minisforum MS-A2 (plus one GPU laptop), LAN-only, on a $0 budget — constraints treated as design. This is the full inventory - the numbered spine is the value path (raw data → data products); each row shows the tool, its job, and a real example of it in use.

Two lanes: Claude Code sees & builds · the operator agent (sees & does — local gpt-oss brain, LangGraph on mother, live) is the operator half. · Retired/declined: Hermes, Backstage, Jaeger, Strimzi, Airbyte, Airflow, KubeRay.
