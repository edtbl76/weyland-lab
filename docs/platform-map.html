Weyland · Platform Map · 2026-07

One box, the whole data → ML → AI factory.

A homelab where a governed lakehouse is the substrate and two agent lanes close the loop — Claude Code builds, Hermes operates. Every technology below runs on a single bare-metal Minisforum MS-A2 (plus one GPU laptop), LAN-only, on a $0 budget. The spine is the value path: raw data becomes governed data products; the planes underneath keep it running, observable, and controllable from your phone.
