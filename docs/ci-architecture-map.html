Weyland · Continuous Integration

CI Architecture — one pipeline, gate to deploy

Every push to weyland-lab runs a 23-step Woodpecker pipeline: cheap deterministic guards first (a stale doc or a broken policy stops the run before anything builds), then per-language tests, scanners and an integration lane, then build → sign → deploy-handoff. The LAN has no push-webhooks, so it is triggered manually or by a nightly 01:00 NY cron. This is the weyland-lab pipeline (backend: kubernetes — steps are cluster pods); the same Woodpecker server also runs STUD.io's CI on a local backend over rogueone agents.

Trigger & runtime — the LAN has no push-webhooks

Trigger

No GitHub push-webhooks — the cluster is LAN-only. Runs start manually, from woodpecker-cli, or the nightly 01:00 NY cron. GitHub OAuth for login only.

Backend: kubernetes

weyland-lab jobs — each step is a fresh cluster pod on mother's k3s. The default for anything that builds/deploys into the cluster.

Backend: local

STUD.io jobs — steps run on rogueone's 4 agents (host shell + native docker), because that CI needs a real Go/Node/pyenv/Playwright toolchain + docker exec studio_db. Routed by the backend agent label.

Build infrastructure — what the pipeline runs on

buildkitd

A persistent Deployment (:1234 TCP), not a per-step daemon — daemonless BuildKit couldn't do its mounts in an ephemeral k3s step-pod. The build step is a thin buildctl client to it. Warm cache via a registry cache tag.

registry.weyland.lab

The image registry every build pushes git-<sha> to, and the ONLY registry the Gatekeeper policy trusts by default. Fronted by Traefik with a raised read-timeout (big pushes were 499-ing).

Woodpecker server + LAN bridge

One server, mixed fleet. Two NodePorts bridge off-cluster: :30900 gRPC (rogueone agents register, trust = WOODPECKER_AGENT_SECRET) and :30980 HTTP (the CLI, bypassing forward-auth which 302s Bearer calls).

Around the pipeline

Ship loop

ship-images.sh merges the tag-bump PR under a 3-condition gate (same-repo · CI-authored · tags-only), syncs only affected Argo apps, and verifies every bumped image is live on a probe-backed workload.

Watchdogs

pr-staleness + cron-freshness → Alertmanager → Telegram when a PR sits or a cron stops. port-pr-reconcile reaps closed-PR entities the Ocean integration leaves behind.

Weekly scan-suite

Separate cadence from the pipeline: code-scan-suite (21 tools) + sonar-scan CronJobs → Port security_scan / code_quality / code_hotspot → Code Health dashboard.

Admission control

Gatekeeper K8sImageSignature in dryrun: images must come from a signed/reviewed registry. The Rego cannot verify signatures (no egress) — cosign verify does that in CI. Audit: 0 violations across 49 reviewed publishers.

Two backends, one server

kubernetes backend = weyland jobs as cluster pods. local backend = STUD.io CI on rogueone's 4 agents (real Go/Node/Playwright toolchain). Routed by the backend agent label.
