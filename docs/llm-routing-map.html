LLM Routing Map

Use-case aliases → provider fallback chains, served by LiteLLM. A client sends only the alias (e.g. wl-coding); LiteLLM picks the primary and fails over down the chain on network / 5xx / 429 / timeout — server-side, transparent.

Provider egress → Bifrost (2026-08-01): the hosted lanes now egress through Bifrost (LiteLLM → Bifrost → provider), so every funded call is recorded with cost / tokens / latency and attributed to the realm-llm virtual key — no LiteLLM DB. LiteLLM still owns the aliases and the fallback chains below; the local Ollama lanes (wl-rag · wl-reason · wl-judge) stay direct to rogueone.

◆ LIVE — LiteLLM aliases + fallback  ·  hosted lanes egress through Bifrost (per-VK cost obs)
Free — $0 (self-hosted or free tier) Funded — prepaid credits Metered — pay-per-token, budget-capped local on rogueone GPU tools tool-calling web web search
Fallback philosophy. Primary = cheapest capable source (free/local where private). Chains are multi-rung: a dry paid provider (402 / 429) is skipped by cost management, not an error — the router walks on — and every chain ends in a free, always-on rung so it can never hard-fail.
Provider status (2026-08-02). Live & egressing through Bifrost: anthropic · groq · gemini · opencode-zen · xai · openrouter · deepseek · openai · perplexity. Only cerebras is 402 (unfunded) — kept in the chains (routes through Bifrost, works the moment it's funded).
