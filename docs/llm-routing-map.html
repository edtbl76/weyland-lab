LLM Routing Map

Use-case aliases → provider fallback chains, served by LiteLLM. A client sends only the alias (e.g. wl-coding); LiteLLM picks the primary and fails over down the chain on network / 5xx / 429 / timeout — server-side, transparent.

Free — $0 (self-hosted or free tier) Funded — prepaid credits Metered — pay-per-token, budget-capped local on rogueone GPU tools tool-calling web web search
Fallback philosophy. Primary = cheapest capable source (free/local where private). Chains are multi-rung: a dry paid provider (402 / 429) is skipped by cost management, not an error — the router walks on — and every chain ends in a free, always-on rung so it can never hard-fail.
Notes. wl-agentic skips Groq — its free tier is tool-free (8k TPM can't carry the tool payload). wl-search / wl-tts are near-single-source, so their chains are short. Media lanes route on the image / audio / video endpoints, not chat.
