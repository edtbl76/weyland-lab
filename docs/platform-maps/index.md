# Platform Maps

Two big-picture, hand-authored views of the weyland platform:

- **[Platform Map](platform-map.md)** — the full technology inventory, laid out as the data → ML → AI **value path**
  (raw data → data products) plus the three platform planes underneath.
- **[Data Mesh Map](data-mesh-map.md)** — the **data-mesh architecture**: Dehghani's four principles, the FAIR-based
  data-product tenets, the eight-layer lakehouse stack, and the data products — each linking to a live demo.

Both open full-screen and share one design system; the Data Mesh Map is the architecture lens, the Platform Map is
the exhaustive inventory.
